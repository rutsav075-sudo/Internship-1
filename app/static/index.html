Gemini connection

Checking server configuration…

GEMINI_API_KEY=your_key_here
GEMINI_MODEL=gemini-3.1-flash-lite

Add these to the server’s .env file and restart it. Never paste your API key into browser code or commit it to a repository.

Unlock analytics to run a live connection test. Each test makes one Gemini request.
A configured key is not proof of a working connection. Send a question to validate the provider; failures use a clearly labelled FAQ fallback.
⊞

Analytics access

Analytics contains conversation text. Unlock it with your server’s ADMIN_TOKEN.

Analytics is locked.

The token is held in memory only and is cleared when the page reloads. An unguessable token is required for viewing, exporting and deleting conversation data.

Workspace operations

Database, model and answer performance. No extra Gemini requests.

Unlock analytics to view operational monitoring.
    Metrics are a snapshot, not an external alerting service.

    Privacy & data controls

    Questions and answers are stored locally for analytics. Common emails and phone-like numbers are redacted before storage and Gemini requests, but this is not comprehensive personal-data detection. Relevant FAQ references and the current redacted question are sent to Google when Gemini is enabled. Browser chat display is session-only; refreshing clears the display, not the server records.

    Delete conversation recordsPermanently removes all stored questions, answers and feedback. Requires admin access.
