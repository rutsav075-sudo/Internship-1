API examples use synthetic data. Never send children’s personal information. Protected routes require Authorization: Bearer YOUR_ADMIN_TOKEN. The Gemini key is read only from the server environment.

Endpoints

OpenAPI schema ↗
METHOD PATH ACCESS DESCRIPTION
GET /api/health Public Server health, provider configuration status and configured model. Does not validate the API key.
GET /api/knowledge Public Eight demo FAQ references.
POST /api/chat Public, rate-limited Question → classification, retrieval, optional Gemini generation, storage.
POST /api/feedback/{event_id} Session capability Set or replace a message rating. Requires the originating session UUID.
GET /api/evaluation Public Held-out classifier metrics and confusion matrix.
GET /api/analytics Admin All-time counts, intent distribution, latency, feedback, UTC-day counts and the 20 latest conversations.
GET /api/export Admin CSV export, with spreadsheet formula neutralization.
DELETE /api/conversations Admin Permanently delete all conversation records and feedback.
GET /api/ready Public Readiness of loaded models and a database read. Does not validate Gemini or prove write permissions.
GET /api/conversations?limit=20&offset=0 Admin Paginated conversations. Limit 1–100; offset 0–1,000,000. Session capabilities are not exposed.
GET /api/provider/status Admin Process-local last verified success, sanitized failure category, counters and credential/quota cooldown.
POST /api/provider/check Admin, rate-limited Run one real generation with sample data. Uses API quota; does not store a conversation. Maximum 3 checks per client per minute.
GET /api/operations Admin Read-only database/model/provider/traffic snapshot, including p95, fallback share, dataset fingerprint and clear metric scope. Does not invoke Gemini.

Send a question

Use a random UUID for each conversation session. Message length is 2–2,000 characters. Each question is answered independently. 

POST /api/chat
Content-Type: application/json

{
  "message": "How do I apply for admission?",
  "session_id": "2ceee705-3b67-4f37-8d1f-2f03a5377351"
}

Returns id, answer, intent, confidence, mode, latency_ms, sources, notice. Mode is gemini, retrieval or no_match. The model confidence is not calibrated accuracy.

Rate an answer

Use the event ID returned by the chat request and the same session UUID. A repeated request updates the existing rating instead of adding another vote. 

POST /api/feedback/{event_id}
Content-Type: application/json

{
  "session_id": "2ceee705-3b67-4f37-8d1f-2f03a5377351",
  "value": 1
}

value must be 1 (helpful) or -1 (not helpful). Returns {"ok": true}.

Error handling

401 Missing, unconfigured or incorrect admin token. 404 Feedback event not found in the provided session. 413 Request body exceeds 16 KiB. 422 Invalid input. 429 More than 20 questions per 60 seconds from a client address. Gemini failures return a successful, explicitly labelled reference FAQ fallback when a source is available. Raw provider errors and credentials are never returned.

The in-memory limiter is per process and uses the direct client address; a reverse proxy may group users. Use an edge rate limiter and a trusted proxy policy for public deployment. Server storage or infrastructure failures can still return HTTP 5xx; monitor these in staging.

Self-contained documentation. No external scripts or CDN dependencies.
